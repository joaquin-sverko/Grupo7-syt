## Objetivo del Proyecto
El objetivo principal de este trabajo integrador es configurar, administrar y transformar una **Raspberry Pi 3** en un **router funcional** para la red local, abordando desde la instalación básica del sistema operativo y administración remota por SSH, hasta el enrutamiento y la gestión de servicios de red.
